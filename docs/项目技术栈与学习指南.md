## 2. 核心技术栈

### 2.1 WPF（Windows Presentation Foundation）

- **XAML**：声明式 UI（窗口 `Window`、用户控件 `UserControl`、布局 `Grid`/`StackPanel`/`Border` 等）。
- **代码隐藏（Code-Behind）**：`*.xaml.cs` 中处理事件（如按钮 `Click`、输入框 `KeyDown`、下拉框 `SelectionChanged`）。
- **数据绑定**：`DataGrid`、`ComboBox`、`TreeView` 等与 `ObservableCollection`、模型属性绑定。
- **样式与资源**：`Window.Resources` / `UserControl.Resources` 中定义 `Style`、`DataTemplate`、`HierarchicalDataTemplate`。
- **模板列**：`DataGridTemplateColumn` + `Ellipse` 等实现自定义单元格（例如状态指示灯）。

**学习建议**：先掌握 XAML 布局与绑定，再学 `Style`/`Template`，最后做 `DataGrid` 与 `TreeView` 的复杂模板。

---

### 2.2 C# 语言与 BCL

项目中常见用法包括：

- **`async` / `await`**：异步 TCP 读写，避免阻塞 UI 线程。
- **`ObservableCollection<T>`**：集合变更时 UI 可刷新（配合 WPF 绑定）。
- **`LINQ`**：`Where`、`OrderBy`、`Select`、`FirstOrDefault` 等做内存中筛选与排序。
- **`System.Net.Sockets`**：`TcpClient`、`NetworkStream`，ASCII 编码收发。
- **`System.IO`**：`File.ReadAllText` / `WriteAllText` 读写本地配置文件。
- **`System.Text.Encoding`**：如 `Encoding.ASCII` 处理协议字节流。

**学习建议**：熟悉 `async void` 在 UI 事件中的利弊（仅适合事件入口；业务层可改为返回 `Task`）。

---

### 2.3 配置与持久化

#### JSON（Newtonsoft.Json）

- **包**：`Newtonsoft.Json` **13.0.3**
- **用途**：序列化/反序列化 `materials.json`、`config.json` 等。
- **典型 API**：`JsonConvert.SerializeObject`、`JsonConvert.DeserializeObject<T>`

**学习建议**：了解 `[JsonProperty]` 等特性（本项目若扩展字段可用来兼容旧 JSON）。

#### 本地文件约定

- 物料配置：`materials.json`（与可执行文件工作目录相关，运行时通常与 `bin\Debug` 同级或当前工作目录）。
- 机器/连接配置：`config.json`（`Config.cs` 中定义路径）。

---

### 2.4 Excel 处理（ClosedXML 生态）

- **主包**：`ClosedXML` **0.105.0** — 用 C# 读写 `.xlsx` 等。
- **相关依赖**（由 ClosedXML 引入，在 `packages.config` 中可见）：
  - `ClosedXML.Parser` 2.0.0  
  - `DocumentFormat.OpenXml` / `DocumentFormat.OpenXml.Framework` 3.1.1  
  - `ExcelNumberFormat` 1.1.0  
  - `SixLabors.Fonts` 1.0.0  
  - `RBush.Signed` 4.0.0  
  - `Microsoft.Bcl.HashCode` 1.1.1  
  - `System.Memory`、`System.Buffers`、`System.Numerics.Vectors`、`System.Runtime.CompilerServices.Unsafe` 等

**典型用法**：`XLWorkbook` → `Worksheet` → `RangeUsed().RowsUsed()` 遍历行，`Cell(n).GetValue<string>()` 读单元格。

**学习建议**：掌握“从第几行开始是数据、各列语义”的约定；大文件时注意性能（必要时分批或只读必要列）。

---

### 2.5 网络通信（TCP 客户端）

- **`TcpClient.ConnectAsync`**：异步连接。
- **`NetworkStream.WriteAsync` / `ReadAsync`**：异步发送与读取。
- **协议细节**：例如用 `0x02`（STX）、`0x03`（ETX）包裹报文；响应中判断是否包含 `ACK` 等业务约定。

**学习建议**：补充学习超时、重连、粘包/半包（若协议变长或分片）等工业场景常见问题。

### 2.6 NuGet 与还原方式

本项目为 **packages.config** 引用程序集：

- 还原方式示例：`nuget restore testDemo\GHPHandShake.csproj -PackagesDirectory packages`
- 程序集通过 `.csproj` 中 `<Reference Include="..."><HintPath>..\packages\...</HintPath></Reference>` 引用。

## 4. 架构风格说明（便于你对照学习 MVVM）

当前 **testDemo** 以 **代码隐藏 + 直接操作模型** 为主，**未强制采用完整 MVVM**（例如未全面使用 `INotifyPropertyChanged` 的 ViewModel 层、未使用 `ICommand` 统一命令）。

若你希望向 **标准 MVVM** 演进，可逐步引入：

1. 将界面状态与命令抽到 **ViewModel**（实现 `INotifyPropertyChanged`）。  
2. 用 **`ICommand`** 或 **`RelayCommand`** 替代大量 `Click` 里的大段逻辑。  
3. 通过 **`Binding`** 减少在代码里直接 `ItemsSource = ...` 的手动赋值（也可用兼容方式保留）。
